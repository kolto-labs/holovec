# 📚 Source Catalog

The full itemized list of lore-relevant sources tracked by HoloVec, with the release and publisher details **as recorded in the repository catalog**. Where the catalog does not record a publisher or date, this page says so rather than guessing.

Primary data lives in [`catalog/sources/source-inventory.json`](../catalog/sources/source-inventory.json) and [`catalog/works/`](../catalog/works/). This page is a human-readable summary of those files.
